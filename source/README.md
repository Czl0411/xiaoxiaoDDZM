# DZMM 网页群聊机器人

这是一个本地运行的 DZMM 网页群聊真实账号机器人。它不是官方 API Bot，也不是 QQ / 微信 / Telegram 机器人，而是通过 Playwright 控制你自己登录的 DZMM 网页账号，读取群聊消息并按配置回复。

程序固定只处理 `/` 开头命令。普通聊天不会触发回复；如果用户发送 `/xxx` 但没有命中内置功能或自定义命令，会回复“命令错误”。

本项目不包含验证码绕过、风控绕过、批量刷屏、批量拉群、批量私信、隐藏自动化痕迹等功能。别把正常工具往刑具方向拧，没必要，也不安全。

## 快速开始

1. 安装 Python 3.11 或更高版本。
2. 双击 `start.bat`。
3. 等待依赖安装完成，管理界面地址是 `http://127.0.0.1:7868`。
4. 在“连接设置”点击“打开 DZMM”。
5. 在机器人弹出的浏览器里登录 DZMM 账号。
6. 进入目标群聊，复制群聊 URL。
7. 在“连接设置”填写群聊 URL，点击“保存设置”。
8. 点击“识别页面”，再点击“测试读取”，确认能看到群聊消息。
9. 配置“功能中心”“商店配置”或“自定义命令”。
10. 点击“恢复机器人”开始监听。

## 首次登录

第一次启动需要手动登录 DZMM。登录状态保存在：

```text
data/browser_profile/
```

下次启动会复用这个浏览器资料目录，通常不需要重新登录。如果登录失效，重新打开 DZMM 登录即可。换账号时先暂停机器人，然后在“连接设置”点击“重置登录”，也可以手动删除 `data/browser_profile/`。

## 命令模式

机器人只处理 `/` 开头消息：

- `/测试`：默认自定义命令，回复“机器人在线”。
- `/签到`：每日签到，记录连续天数并发放奖励。
- `/余额`：查看当前金币或积分。
- `/商店`：查看已上架商品。
- `/购买 商品名`：扣除积分并加入背包。
- `/背包`：查看当前用户物品。
- `/帮助`：查看命令说明。

普通消息会被忽略，例如“你好”“在吗”“价格多少”都不会触发。要触发就必须配置成 `/菜单`、`/客服`、`/价格` 这类命令。

## 用户数据库

程序使用 SQLite 保存用户数据，核心文件是：

```text
data/bot.db
```

所有用户数据公用这一个数据库文件，包括用户档案、签到记录、积分流水、商店商品、购买记录和背包物品。换电脑时不要只复制源码，必须一起复制 `data/bot.db` 和 `data/config.json`，否则规则和用户数据当然会丢，软件再高级也不能凭空读心。

当前用户识别主要基于 DZMM 昵称，保存内容包括：

- 用户昵称
- 消息数
- 触发次数
- 积分或金币余额
- 签到总次数
- 连续签到天数
- 最近签到日期
- 背包物品

这意味着签到、商店、积分、背包都已经有数据库基础。后续要扩展抽奖、任务、等级、称号、兑换码，也可以继续基于用户表、交易表和背包表扩展。

## 创建第一条自定义命令

进入“自定义命令”，填写：

```text
命令名称：菜单
命令触发词：/菜单
回复模式：固定回复
回复内容：
可用命令：
/签到
/余额
/商店
```

保存后，用户在群里发送 `/菜单` 才会触发。发送“菜单”不会触发。

## 回复模式

- 固定回复：每次回复同一句。
- 随机回复：从多行回复中随机选一条。
- 顺序回复：每次按下一条回复，循环发送。
- 多段回复：一条规则触发后分多条消息发送，会受发送间隔和频率限制控制。

## 模板变量

- `{user}`：当前发言人昵称。
- `{message}`：用户原始消息。
- `{time}`：当前时间。
- `{date}`：当前日期。
- `{count}`：当前规则累计触发次数。
- `{random:你好|在的|收到}`：随机选择一个词。
- `{newline}`：换行。

示例：

```text
你好，{user}{newline}现在时间是 {time}
```

## 商店配置

进入“商店配置”可以创建商品：

```text
商品名称：徽章
价格：100
库存：-1
商品说明：永久纪念徽章
```

用户发送 `/商店` 查看商品，发送 `/购买 徽章` 购买。库存 `-1` 表示不限量。

## 启用和停止

- “恢复机器人”：启用监听和自动回复。
- “暂停”：停止自动回复，但浏览器和管理界面仍运行。
- “紧急停止”：立即暂停机器人，适合异常连续发言时使用。

启用时程序会先建立消息基线，当前屏幕上的旧消息不会触发自动回复。

## 常见问题

### 机器人没有回复

可能原因：

- 机器人未启用。
- 没有在机器人浏览器里登录 DZMM。
- 群聊 URL 没填写或没打开。
- 消息不是 `/` 开头。
- 命令没有启用或没有命中。
- 触发冷却时间或达到频率限制。
- 页面选择器失效。

处理方法：

1. 看“仪表盘”的登录状态和机器人状态。
2. 点击“测试读取”。
3. 点击“识别页面”重新检测选择器。
4. 查看“消息监控”和“日志中心”。

### 机器人重复回复

可能原因：

- 页面消息结构变化导致去重不稳定。
- 机器人没有正确识别自己消息。
- 扫描频率过高。

处理方法：

- 确认安全设置开启。
- 降低扫描频率到 3-5 秒。
- 开启全局冷却。
- 重新识别页面。

### 无法发送消息

可能原因：

- 输入框选择器错误。
- DZMM 页面没有聚焦。
- 账号登录失效。
- 平台限制发送。

处理方法：

- 点击“发送测试消息”。
- 重新打开群聊。
- 重新登录。
- 查看错误日志。

### 换电脑运行

复制整个 `dzmm-web-bot` 文件夹即可。重要数据：

```text
data/config.json
data/bot.db
data/browser_profile/
```

如果新电脑 Python 和依赖正常，双击 `start.bat` 就能运行。登录状态是否可复用取决于浏览器资料和平台策略；如果失效，重新登录一次。

## 备份

建议定期备份：

```text
data/config.json
data/bot.db
```

规则也可以在“自定义命令”页面导出为 JSON。

## 安全建议

- 不要刷屏。
- 不要用于骚扰。
- 不要绕过平台限制。
- 使用自己的账号和自己参与的群聊。
- 先在小群和新账号测试。
- 不要让多个规则使用相同命令。
- 出现异常连续发言时立即点击“紧急停止”。
